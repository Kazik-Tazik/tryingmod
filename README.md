# Kamizelka's Bizarre World Mod

**Version:** 1.0.0  
**Minecraft Version:** 1.20.1  
**Forge Mod**  
**Requires:** [TerraBlender](https://www.curseforge.com/minecraft/mc-mods/terrablender)

---

## Description

Kamizelka's Bizarre World Mod is a chaotic and creative expansion for Minecraft. Built around strange ideas and funny twists, this mod adds new mobs, items, blocks, and a portal.
This is a personal project and my first Minecraft mod. It’s meant to be strange, fun, and experimental.

---

## Installation

1. Install Minecraft Forge for version 1.20.1.
2. Install the [TerraBlender](https://www.curseforge.com/minecraft/mc-mods/terrablender) mod.
3. Download the latest version of this mod.
4. Place the `.jar` file into your Minecraft `mods` folder.
5. Launch Minecraft and enjoy the chaos.
